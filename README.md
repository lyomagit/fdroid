Личный каталог Android-приложений.

Добавьте в F-Droid: [https://lyomagit.github.io/fdroid/repo/](https://lyomagit.github.io/fdroid/repo/?fingerprint=5FE86468F45CB87C3352168430A45D42D3BCC4D3F3E541EDDA8B9E42B8269920).

Отпечаток ключа каталога: `5FE86468F45CB87C3352168430A45D42D3BCC4D3F3E541EDDA8B9E42B8269920`.

Любимые коллеги — версия `2.3-rc1`, код `5`. Это версия-кандидат; проверка оператора MMS и конкретных Huawei ещё не завершена.

Приложение требует стандартных ролей Android для фильтрации звонков и обработки SMS. Входящие MMS поддерживаются; отправка пользовательских MMS-вложений пока не реализована.

Индексы подписываются локально. Приватные ключи и пароли в этом репозитории отсутствуют. Лицензия всего приложения пока не объявлена; включённые компоненты сохраняют собственные уведомления.
